# Sanctum: защита приватных данных в Claude Code

Sanctum заменяет приватные данные — адреса почты, IP, ключи API, пароли и другие секреты — локальными псевдонимами вида `[EMAIL-1]` до того, как они попадут к модели. Соответствия хранятся в зашифрованном виде только на вашем устройстве. Локальные инструменты получают исходные значения: команда с `[KEY-1]` выполнится с настоящим ключом, а файл, записанный моделью, будет содержать настоящие данные. Плагин работает только через хуки Claude Code, без прокси, сетевого порта и изменения `ANTHROPIC_BASE_URL`.

## Что защищается

- Ваши сообщения: оригинал блокируется, модель получает замаскированную копию.
- Файлы, упомянутые через `@`: если в них есть приватные данные, они не прикладываются, и модель читает их через маскируемый Read.
- Вывод всех инструментов: терминал, чтение файлов, поиск, веб, MCP, субагенты.
- В ответах модели на экране вы видите настоящие значения серым цветом; модель видит только псевдонимы.

## Установка

Соберите плагин из исходников Sanctum (нужен Rust 1.88+):

```sh
cargo build --release --locked --bin sanctum-guard
target/release/sanctum-guard package-claude --output dist/sanctum-privacy
```

Затем в Claude Code:

```
/plugin marketplace add /абсолютный/путь/dist/sanctum-privacy
/plugin install sanctum-privacy@sanctum-local
```

Перезапустите сессию, чтобы хуки загрузились. Защиту выключает `sanctum-guard settings --enabled false`.

## Ограничения

`CLAUDE.md`, память, навыки, выделение в IDE, изображения и файлы, приложенные кнопкой в интерфейсе десктопа, Claude Code передаёт модели без хуков. Маскирование рассчитано на случайную утечку и не остановит модель, которая намеренно преобразует значения. Подробности: [docs/CLAUDE_CODE.md](../../docs/CLAUDE_CODE.md).
