# История изменений

## 1.0.0

- Единая версия движка и плагинов Sanctum для первого публичного релиза.
- Русская документация, описания плагинов, справка, сообщения обработчиков событий и скриптов установки и упаковки.
- Распознавание на русском и английском языках с проверками Unicode.
- Локальное маскирование, зашифрованные соответствия, предварительная подсветка и восстановление поддерживаемых локальных аргументов через закреплённую нативную серверную часть.
- Установка, удаление, восстановление и откат с журналом транзакций.
- Проверка согласованности версий и отклонение устаревших исполняемых файлов.
- Архивы исходников, лицензия GPLv3, уведомления upstream и контрольные суммы.
- Удалены Python-прототип, устаревшие диагностические скрипты, генератор оформления и каталог удалённого плагина. Тесты и необходимые скрипты сохранены для проверки и сборки.
- Плагин `sanctum-claude` для Claude Code: маскирование запросов и вывода инструментов и восстановление значений для локальных инструментов только через хуки, без прокси и сетевого порта. Подробности: [Sanctum для Claude Code](docs/CLAUDE_CODE.md).
- Адрес электронной почты больше не захватывает префикс вида `owner=`.

Добавлена экспериментальная поддержка Windows x64: расширения `.exe`, DPAPI, приватные DACL, Windows-блокировки, Job Object, локальные команды cmd/PowerShell, запускатель `.cmd`/PowerShell и создание профилей совместимости из настоящих компонентов. Проверки Windows GNU выполняются через Docker/Wine; отдельный workflow настроен для MSVC и проверки нативного патча, но ещё не запускался на GitHub. Готовый проверенный профиль Desktop пока есть только для Linux x86-64; настоящий Windows Desktop ещё не проверен. Статус автоматических и ручных проверок: [проверка релиза](docs/RELEASE.md).
