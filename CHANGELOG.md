# История изменений

## 1.0.0

- Единая версия движка и плагинов Sanctum для первого публичного релиза.
- Русская документация, описания плагинов, справка, сообщения обработчиков событий и скриптов установки и упаковки.
- Распознавание на русском и английском языках с проверками Unicode.
- Локальное маскирование, зашифрованные соответствия, предварительная подсветка и восстановление поддерживаемых локальных аргументов через закреплённую нативную серверную часть.
- Установка, удаление, восстановление и откат с журналом транзакций.
- Проверка согласованности версий и отклонение устаревших исполняемых файлов.
- Архивы исходников, лицензия GPLv3, уведомления upstream и контрольные суммы.
- Удалены Python-прототип, устаревшие диагностические скрипты, генератор оформления, каталог удалённого плагина и пустой пакет совместимости `sanctum-prompt-guard` (команда `sanctum-guard package`), а также экспериментальный локальный HTTP-шлюз (`sanctum prepare`, `serve`, `package`, `session-start`) и его плагин `sanctum-rust`: Sanctum больше не открывает сетевых портов. Тесты и необходимые скрипты сохранены для проверки и сборки.
- Плагин `sanctum-privacy` для Claude Code: маскирование запросов и вывода инструментов и восстановление значений для локальных инструментов только через хуки, без прокси и сетевого порта. Плагин входит в комплект релиза (каталог `claude/`) и проходит проверку `claude plugin validate`, в том числе по правилам каталога плагинов. Подробности: [Sanctum для Claude Code](docs/CLAUDE_CODE.md).
- Запрос с упомянутым через `@` файлом, в котором есть приватные данные, блокируется: Claude Code не прикладывает файл, а модель читает его через маскируемый Read.
- Соответствия Claude Code привязаны к проекту и сохраняются после возобновления, форка и `/clear`.
- Плагин Claude Code проверен на Windows 11 в десктопном приложении: команды Bash с псевдонимами выполняются через Git Bash и `run-command`, исходные значения не попадают в журнал сеанса.
- В ответах модели на экране псевдонимы заменяются исходными значениями тёмно-серого цвета; модель по-прежнему видит заглушки.
- Меньше ложных срабатываний на исходном коде, упоминаниях файлов через `@` и идентификаторах API Claude: на собственном коде Sanctum их стало втрое меньше.
- Адрес электронной почты больше не захватывает префикс вида `owner=`.

Добавлена экспериментальная поддержка Windows x64: расширения `.exe`, DPAPI, приватные DACL, Windows-блокировки, Job Object, локальные команды cmd/PowerShell, запускатель `.cmd`/PowerShell и создание профилей совместимости из настоящих компонентов. Проверки Windows GNU выполняются через Docker/Wine; отдельный workflow настроен для MSVC и проверки нативного патча, но ещё не запускался на GitHub. Готовый проверенный профиль Desktop пока есть только для Linux x86-64; настоящий Windows Desktop ещё не проверен. Статус автоматических и ручных проверок: [проверка релиза](docs/RELEASE.md).
